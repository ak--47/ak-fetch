### 4. CHANGELOG.md ✅
Added two entries under "Changed" section:

**Invalid JSON responses** (N-3): Moved/duplicated behavior change from "Fixed" section with migration note. Pre-2.1.0 behavior: 200 response with JSON content-type but unparseable body produced error (counted in result.errors). New behavior: Resolves successfully with raw text string as body.

**Retry surface widened** (N-5): Connection resets (ECONNRESET, ECONNREFUSED, EHOSTUNREACH, etc.) and body/header timeouts now classified retryable NetworkError/TimeoutError, including on POST requests. Added idempotency caveat and remediation advice (retryOn/retryHandler or retries: 0).
