## Benchmark Comparison

### Status

**2.1.0 Branch:** ✅ Complete (9.67 minutes, all tests passed)  
**Main Branch (2.0.16):** ❌ Complete but FAILED - 100% benchmark failure rate

### Critical Finding: Main Branch Completely Non-Functional

The main branch (2.0.16) benchmarks **failed every single test** with "Invalid data format" errors when attempting to send data to the Mixpanel API. This is direct empirical evidence that bug **A1 (double-transform corruption)** makes the library fundamentally broken for production use with the Mixpanel preset.

**Main Branch Error Pattern:**
```
❌ Failed: Invalid data format
```
This occurred on every benchmark test (concurrency 5/10/15/25/40, batch sizes 250/500/1000/2000, all resilience tests).

**Root Cause:** Finding A1 — transform applied twice to every record, corrupting the data structure sent to Mixpanel API.

**2.1.0 Result:** All tests pass successfully with 0% error rate, validating the fix.
